# LuxeLoop — 명품 공유 P2P 플랫폼 (데모)

**LuxeLoop**는 유휴 명품(가방·시계·주얼리·의류)을 가진 사람이 이를 대여해 주고,
필요한 사람이 수수료를 내고 빌리는 **P2P 마켓플레이스**입니다. 플랫폼은 매칭·예약과
함께, 무엇보다 중요한 **신뢰 — 정품 인증·보증금·대여자/소유자 보호**를 담당합니다.

English docs: [README.md](./README.md)

### ▶ 라이브 데모: https://clsoftlab-lang.github.io/luxury-rental-p2p/

브라우저에서 **데모 모드**로 완전히 동작하는 단일 페이지 앱(SPA)입니다.
빌드 과정·서버·회원가입이 필요 없습니다.

---

## 왜 신뢰가 핵심인가

명품 P2P는 양측 모두 안전하다고 느껴야만 성립합니다. LuxeLoop는 안전장치를
부가 기능이 아니라 **1급 기능**으로 설계했습니다:

1. **정품 인증 접수** — 소유자가 아이템을 등록하면 전문 인증사(데모: 모의)가 로고·각인·소재·시리얼을 검수합니다.
2. **인증 배지 발급** — 통과 시 인증 코드와 배지를 발급해 대여자가 신뢰할 수 있게 합니다.
3. **보증금 에스크로** — 대여자의 환급성 보증금을 결제 시 예치(데모)하고 정상 반납 시 환급합니다.
4. **선택형 손상·분실 보험** — 일일 보험료로 사고를 커버(데모)하며 자기부담금이 적용됩니다.
5. **반납 검수 & 체크리스트** — 사진·상태 체크리스트를 상호 확인해 분쟁을 예방하고 보증금을 정산합니다.
6. **양방향 리뷰** — 대여자·소유자가 서로 평가해 커뮤니티 신뢰를 축적합니다.

> **실제 정품 판별에는 전문 감정이 필요합니다.** 이 데모는 안전장치가 어떻게
> 맞물려 돌아가는지 체험할 수 있도록 워크플로우를 *시뮬레이션*할 뿐입니다.

## 주요 기능

- **탐색** — 40개 시드 아이템을 카테고리(가방/시계/주얼리/의류)·브랜드·사이즈·일일요금 상한으로 필터, 검색, 정렬(추천/요금/평점).
- **아이템 상세** — 인라인 SVG 사진, 상태 등급, 일일요금·보증금, **대여 가능 날짜 캘린더**, 정품 인증 상태, 소유자 평점.
- **대여 예약** — 기간 선택 → 요금+보증금 자동 계산(기간 할인·서비스 수수료·선택 보험) → **모의 결제**.
- **내 물건 등록** — 대여 놓기 폼(localStorage 저장).
- **정품 인증 & 안전장치 흐름** — 배지·검수 단계·보증금·보험 옵션(모두 모의).
- **양방향 리뷰** — 대여자/소유자 입장으로 리뷰 작성.
- **위시리스트** — ♡로 아이템 저장.
- **부가 기능** — 실시간 요금 계산기, 반납 체크리스트 모달, 손상·분실 보험 옵션, 라이트/다크 테마, 데모 데이터 초기화.

## 로컬 실행

의존성 없음. ES 모듈은 `file://`가 아닌 `http://`가 필요하므로 폴더를 HTTP로 서빙하세요:

```bash
python -m http.server 8994
# 이후 http://localhost:8994 접속
```

검증 실행 (Node 18+):

```bash
node check.mjs        # JSON 파싱 + html 컨테이너 + pricing.js 단위 테스트
node --check app.js   # JS 문법 검사
```

## 데모 모드 경계 (반드시 확인)

> **이 프로젝트는 데모입니다. 실제로 동작한다고 가정하기 전에 읽어주세요:**
>
> - **모든 브랜드명은 가상**(Aureléon, Valmonté, Céribel, Nordveil 등)이며 실존 상표와 무관합니다.
> - **정품 인증·에스크로·보험은 시뮬레이션**입니다. 실제로 인증·예치·보험이 이뤄지지 않습니다.
> - **`localStorage`는 실제 데이터베이스가 아닙니다.** 등록 물건·예약·위시리스트·리뷰는 브라우저에만 저장되며 언제든 삭제될 수 있습니다.
> - **실제 결제·계정·개인정보(PII) 없음.** "결제" 단계는 카드·계좌 정보를 절대 수집하지 않습니다.
> - **실제 서비스로 만들려면:** 전문 정품 인증 파트너, 실제 에스크로·보험, KYC/본인확인, 실 결제 연동, 분쟁 처리, 법률·컴플라이언스 검토가 필요합니다.

## 기술

- 무빌드 정적 SPA: 루트의 `index.html`, 최신 HTML + CSS + ES 모듈 JS, 상대 경로만 사용.
- 반응형 모바일 퍼스트, 라이트 + 다크 테마.
- 모듈: `pricing.js`(요금/보증금/기간 산식), `storage.js`(localStorage try/catch + 초기화), `svg.js`(인라인 SVG 플레이스홀더), `app.js`(해시 라우터 + 뷰).
- 데이터: `data/items.json`(40개), `data/config.json`(카테고리·요금·안전장치 문구).
- CI: `.github/workflows/ci.yml` — 모든 JS `node --check` + `node check.mjs`.
